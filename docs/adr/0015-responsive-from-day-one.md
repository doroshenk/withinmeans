# 0015. Every screen responsive from day one

- **Status:** Accepted
- **Date:** 2026-11-19

## Context

The spec left phone polish to the last phase, but the owner will enter data from his phone from Phase 2.

## Decision

Every screen ticket works at 1440px and 390px with its main empty state. Phase 6 keeps only phone-only flows, bottom sheets, remaining empty states and the accessibility audit.

## Consequences

Screen tickets are 20–30% bigger.
